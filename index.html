01 / About

Data science that ends in a working product.

I'm a B.Tech Computer Science & Engineering (Artificial Intelligence) graduate from JECRC University, Jaipur, with 13 months of hands-on experience across data analysis and applied AI/ML internships.

My work sits at the intersection of two things: rigorous analysis — statistics, feature engineering, model evaluation, KPI design — and getting it in front of people — dashboards, bots, browser extensions, and real-time applications. A model that's 95% accurate in a notebook is only useful once someone can actually query it.

Taxi Trip Analytics & Model-Performance Dashboard

A 28-sheet Tableau workbook built on the NYC Yellow Taxi trip dataset, covering both the data itself and the machine-learning pipeline built on top of it.

  • Fare, tip and trip-distance analysis broken out by payment type and distance category
  • Data-quality tiles — missing-value percentage, missing values by feature, records processed by day
  • Model-performance monitoring — accuracy, F1, precision/recall KPIs, model comparison and feature importance
  • Pipeline throughput — records-per-minute, pipeline execution time, rows processed by day

Built with Tableau. Not yet published to Tableau Public — the workbook is available on request, and an embedded view will go here once it's hosted.
